# Contentity

This repository implements a web application framework and deployment system
for web sites running under Apache/mod_perl.

You almost certainly shouldn't consider using this for your own projects
unless you really like living dangerously.

The first version was written around 2004 as an amalgamation of
existing CPAN modules, unpublished Open Source modules I had written
to process web forms, and various other bits of application specific
code that I had written for a number of commercial clients.  It was
actively developed and extended for around 20 years and continues to be
used as the framework for several production web sites.  However, it
is now in "maintenance-only" mode and should not be considered for new
projects.

It has never been released to CPAN, and probably never will be.
It is not even "officially" Open Source software.  However you
are welcome to use it or adapt it for you own needs, but be warned
that it is not actively maintained and does not come with any
guarantee of fitness for purpose.

It is a framework that I built in the days when Perl was still a good choice
for web programming, to help *me* build and maintain website for paying
clients.  Even I wouldn't consider starting a new project with it.

You have been warned.  Several times.

If you are looking to build a web application framework in Perl then
[Mojolicious](https://www.mojolicious.org/) is a great place to start.
